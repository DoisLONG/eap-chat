# 验收清单

按根目录 `AGENTS.md`，以下验证由用户在目标环境执行；当前项目未配置自动化测试、Lint 或格式化脚本。

## 所有前端改动

- [ ] `npm run build` 成功。
- [ ] 受影响页面能通过菜单、深链接、刷新和浏览器前进/后退正常访问。
- [ ] 中文、英文、泰文的新增或修改文案完整；布局、Element Plus 组件和响应式行为不回归。
- [ ] 加载、空数据、网络失败和 401 登录失效行为可理解且可恢复。

## 路由、接口与权限改动

- [ ] 菜单、`router/index.js`、i18n 和页面入口同步；隐藏路由不意外出现在菜单。
- [ ] 请求方法、路径、认证头、分页字段及响应适配与实际后端契约一致；开发代理和 Nginx 运行时代理保持同一前缀语义。
- [ ] 按真实角色验证前端可见性与后端授权；不把 `v-auth` 或静态菜单当成已确认的完整权限体系。

## 练习与考试改动

- [ ] 练习列表、分类树、上传/生成、任务状态、题目复核、保存和删除按实际服务响应工作；不使用参考原型的本地模拟数据。
- [ ] 考试列表、详情、题目预览、草稿保存、发布/撤回和删除仅按实际考试服务返回验证。
- [ ] 若修改 Docker/Nginx 或环境变量，用户确认选定部署环境的代理、镜像构建和容器启动；不验证或泄露未授权环境。
