# 历史迁移说明

本文件曾记录“学练考评”恢复阶段，不能作为当前实现计划或后端契约依据。当前源码已包含培训中心的练习管理、题目复核和考试管理入口及前端 API 封装；实际后端、权限、数据库和部署状态仍须按任务逐一确认。

后续需求按以下最小流程执行：

1. 从菜单/路由定位页面，再定位 `src/services/` 中的调用与代理前缀。
2. 对照实际后端服务和目标部署环境确认接口、字段、权限及迁移。
3. 复用 Vue、Element Plus、Router、Pinia、I18n 与既有服务封装；不把 `reference-ui/` 的 HTML、localStorage 或 mock 数据迁入正式页面。
4. 只在确认的调用链内实现，并由用户执行构建和业务验收。

历史提交、原型和旧运行记录只可用于追溯，不能覆盖当前代码或替代验证。
